AI Restaurant Customer Assistant

AI-Powered Restaurant Order Automation with n8n

End-to-end n8n AI Agent automation workflow
Data processing and workflow logic
AI-powered customer ordering conversation
Automated order recording and kitchen management

Project Description

This project is an end-to-end AI-powered restaurant customer service and order automation system built with n8n. The customer sends a message to the restaurant assistant. The message is processed by an AI Agent that understands the customer's request and manages the conversation.

The AI Agent uses a Gemini model through OpenRouter, a custom System Prompt, Conversation Memory, and a Menu Tool connected to the restaurant menu data. The agent can answer customer questions about the menu and guide the customer through the ordering process.

The workflow also makes sure that the required customer information is collected before completing the order (Customer name, Phone number, Order, Address, Order status). If information is missing, the workflow sends the conversation back to the customer. If complete, the order is automatically processed.

Order Data Management

The system automatically stores structured order information such as Order ID, Customer Name, Phone Number, Order Details, Address, and Order Time. The completed order is stored in a Google Sheet. A separate kitchen/order sheet is also updated so the kitchen can receive the new order information. Finally, the customer receives an automated confirmation message.

AI Restaurant Customer Feedback Automation

Customer Feedback Form → AI Agent → Structured Output Parser → Sentiment Classification → Switch → Automated Actions

Project Description

An AI-powered restaurant customer feedback automation workflow that analyzes customer feedback and automatically takes the appropriate action based on the sentiment of each response.

The customer first submits feedback through a form. The feedback is then processed by an AI Agent that analyzes the customer's response and classifies it into one of three categories: Positive, Neutral, or Negative. The AI uses a Structured Output Parser so the result follows a predefined structured format. A Switch node then routes the workflow according to the sentiment.

Automated Actions by Sentiment

POSITIVE: Store the feedback. Automatically send an email to the customer thanking them for their feedback. Encourage them to visit the restaurant again.

NEUTRAL: Store the feedback. Send an email thanking the customer. Invite them to share additional suggestions or improvements through the restaurant's Telegram bot.

NEGATIVE: Store the feedback. Automatically send an apology email to the customer. Inform the customer that the restaurant team will contact them shortly to understand and resolve the issue, with compensation if appropriate. Send an alert to the customer service team through WhatsApp containing the customer's name and issue so the team can follow up.

Technical Architecture & Workflow

Customer ↓ Feedback Form ↓ AI Agent ↓ Structured Output Parser ↓ Sentiment Classification ↓ Switch ├── Positive → Google Sheets → Gmail ├── Neutral → Google Sheets → Gmail → Telegram └── Negative → Google Sheets → Gmail + WhatsApp Customer Service
